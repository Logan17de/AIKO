# AIKO Stories 🐸

A picture-first, Japanese-learning story collection. Follow Ren, a playful and kind-hearted fifth grader, through ordinary days and small adventures.

## Story 01: ぼくの あたらしい 学校

Five chapters and 24 camera-view scenes: Morning, Going to School, Start of School, New Faces, End of the Day.

Choose a picture above Ren, tap the highlighted objects, solve a short Japanese fill-up, and unlock the next picture. Toggle English translations; story progress is stored in the browser.

### Images

The HTML includes built-in illustrated placeholders. Optional artwork can be placed under `stories/story-01-my-first-day/images/scene-01.webp` through `scene-24.webp`. No external runtime dependencies are required beyond an optional font download.
